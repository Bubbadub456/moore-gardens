Moore Gardens! iPhone Shortcut

Post photos straight from the Photos app.

Add “Post to Moore Gardens”

Open this page in Safari on your iPhone, tap the button, then tap Add Shortcut. It asks for the upload password once, when you add it.

Posting a photo

  1. In Photos, select one or more photos and tap Share.
  2. Scroll down and tap Post to Moore Gardens.
  3. Type a title for each photo. Tags and plant name are optional; leave them blank to skip.
  4. You’ll get a notification when each one is saved. It shows on the site about a minute later.

To keep it near the top of the share sheet: Share → Edit Actions → tap the + next to Post to Moore Gardens.

Fixing problems

  1. “Wrong password”: open the Shortcuts app, tap ••• on the shortcut, and change the first text box to the right password.
  2. To edit or delete a photo, use the upload page → Edit photos.
Build it by hand instead
  1. New shortcut. In its settings, turn on Show in Share Sheet and set it to receive Images; if there’s no input, Ask For Photos.
  2. Text: your upload password. Then Set Variable Password to it.
  3. Repeat with Each item in Shortcut Input. Inside the repeat:
  4. Resize Image (Repeat Item) by Longest Edge to 2000.
  5. Convert Image to JPEG, quality 85%, Preserve Metadata off.
  6. Base64 Encode the converted image (Line Breaks: None).
  7. Ask for Input three times: Title, Tags (optional), Plant (optional).
  8. Get Contents of URL: https://www.mooregardens.farm/api/photo?publish=1, Method POST, Header Authorization = Bearer + Password, Request Body JSON with text fields image (Base64 Encoded), title, tags, plant.
  9. Get Dictionary Value message from the result, then Show Notification with it.
